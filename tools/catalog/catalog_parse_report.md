## 五、口径说明（与甲方规则对齐）

1. **size 是型号的尺寸档位**：目录里 000 / 00 / 0 / 1 / 2 … 各自是一档，**前导零原样保留**，
   因此 `0-GPN`、`00-GPN`、`000-GPN` 是**同一型号（GPN）的三个不同 size**，各自是独立产品；
2. 气体类型来自目录每个规格表下方的 `<型号> FOR L.P.G` / `<型号> FOR ACE` 标注，未标注的一律记 `未标注` 并进「待人工确认」，**不臆造**；
3. 本报告只描述**目录本身**；把客户资料包里的产品名锚定到本目录的结论见 `product_anchor_report.md`。
