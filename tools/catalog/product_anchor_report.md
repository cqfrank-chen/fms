## 四、口径与实现

1. **型号识别**：把名字压成「紧凑键」（只留字母数字、小写），在其中定位目录型号；
   连字符 / 空格 / 点号 / 斜杠差异因此自动等价（3GPN ↔ 3-GPN、MC12 ↔ MC-12、6290NX ↔ 6290-NX）；
2. **size 识别**（甲方规则：型号前 / 型号后 / # 后的数字 = size）：
   型号前 N- 或 N#-、型号后 -N / 空格N / N# / #N，以及隔一段描述后的 N# / #N；
3. **安全守卫**：
   · size 必须**逐字符**命中该型号目录档位（0 / 00 / 000 是三档，绝不互相顶替）；
   · 型号必须在边界上（左侧是分隔符/串首，右侧是分隔符/串尾或紧跟合法 size），否则作废
     —— 所以货号 4154 不会被当成型号 41、1380 不会被当成 138 的 size 0；
   · 型号前后**同时**出现数字且不同 → 「尺寸有歧义」，不出结论（如 割嘴 1-GPN 2#）；
   · 型号锚定到了、但旁边数字不是目录档位（PNME18 的 18）→ 同样不锚定（尺寸未定死）。
4. **服务端与工具侧同算法双实现**，由 `tools/catalog/verify_parity.mjs` 逐条比对防漂移。
