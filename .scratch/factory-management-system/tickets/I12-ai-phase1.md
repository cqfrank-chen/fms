# I12 · AI 一期（订单解析/查数/报表摘要/规则预警/学习闭环）

Type: task
Status: open
Phase: ④ 排期AI线（最后一张）
Blocked by: I04（订单解析消费订单录入）、I09（报表摘要消费账目）
Spec: spec.md §8

## Objective

AI 一期五项能力落地：订单解析 / 查数 function calling / 利润月报摘要 / 规则预警 / 学习闭环。

## Scope

- **模型接入**：DeepSeek-V4-Flash（常规）+ qwen3-vl-flash（多模态）+ qwen3-max（复杂推理）；OpenAI 兼容网关可切换
- **订单解析**：邮件/Excel/图片全入口 → 多模态直出 + JSON Schema + 规则校验 + 低置信标红转人工；AI 导入按钮接入 I04
- **查数**：function calling（20-40 个参数化查询工具，订单/库存/账款/排期四域）；只选工具不见 schema
- **报表摘要**：利润月报模板渲染 + LLM 摘要（只解释数字不生成数字，输出回核）
- **规则预警**：安全库存/账龄逾期/交期冲突标红（确定性规则引擎，一期无 LLM 解释）
- **学习闭环**：人工修正回流 few-shot + 校验规则，逐季提升直通率

## Acceptance

- [ ] 订单解析直通率 ≥70%（人工复核后直接确认比例）
- [ ] 查数问答准确率 ≥90%（预置测试集）
- [ ] 报表摘要无数字幻觉（抽查）
- [ ] 规则预警触发正确
- [ ] **阶段④验收完成**：甘特拖排 + 直通率 ≥70% → 四阶段全过，可执行票 12 切换
