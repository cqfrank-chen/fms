# I06 · 报工 + 状态机聚合

Type: task
Status: open
Phase: ② 订单线
Blocked by: I05
Spec: spec.md §4.2/§4.3, §6（入库触发）

## Objective

计划单行报工（办公室 PC 代录完成数量）→ 行进度聚合 → 计划单/订单状态联动 → 触发入库单草稿。

## Scope

- 行级报工：计划单行录完成数量（票 07：办公室 PC 代录）
- 状态聚合：行达标 → 计划单已完成 → 订单已完成 → 进归档
- 报工事件触发入库单草稿（产品/数量/批次预填，仓管确认在 I08）
- 变更联动：草稿态变更自动重生成、确认后人工处置（订单不走冲销）

## Acceptance

- [ ] 行报工后计划单状态正确流转（生产中→已完成）
- [ ] 全部行完成后订单联动完成进归档
- [ ] 报工触发入库单草稿生成（批次号 FG-YYYYMMDD-NN）
