# I04 · 订单录入 + 订单列表/归档

Type: task
Status: open
Phase: ② 订单线
Blocked by: I03
Spec: spec.md §4

## Objective

订单录入（一单多产品，复合包装 + 刻字）+ 订单列表（筛选）+ 归档区（已完成反查）。

## Scope

- 订单单头：客户档案引用 / 客户 PO 号 / 交期 / 备注
- 订单行：产品目录 × 数量 × 单价（币种 USD/RMB） × 刻字需求 × 包装要求
- 包装要求：**复合勾选**（包装盒/套袋/纸箱/不干胶 多选 + 每项规格）+ 模板库（保存/复用/上传样式图）
- 订单列表：状态/客户/单号筛选；详情弹窗
- 归档区：已完成订单折叠，可按客户/单号反查打开
- AI 图片识别导入入口（占位，功能 I12）

## Acceptance

- [ ] 新增订单（多产品行）保存成功，列表可见
- [ ] 复合包装勾选与规格填写正确入库；模板保存后可复用
- [ ] 筛选生效；详情弹窗字段齐全
- [ ] 订单状态=草稿（确认动作 I05）
