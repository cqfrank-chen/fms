# I08 · 仓储域（库存/入库/出库/来料/盘点/冲销）

Type: task
Status: open
Phase: ③ 仓储账目线
Blocked by: I06（报工触发入库）
Spec: spec.md §6

## Objective

仓储域全部实体：库存列表（安全库存标红）/ 入库确认 / 出库单（挂订单+OQC）/ 来料登记 / 盘点 / 冲销。

## Scope

- 库存列表：SKU×批次，安全库存标红预警；允许负库存
- 入库单确认：报工触发草稿 → 仓管确认入账 → 库存+（批次不变）
- 出库单：挂订单、行引用、可分批；OQC 状态（待检/放行/免检），待检不可确认；确认后扣库存 + 生成应收（I09 消费）
- 来料登记单：日期/供应商/物料/数量/批次号/检验状态（IQC 预留）+ 金额生成应付
- 盘点单：实盘→差异→盘盈/盘亏调整单→确认校准
- 冲销：已确认单据开反向单抵销

## Acceptance

- [ ] 库存标红正确；入库确认后库存+
- [ ] 出库：OQC 待检拦截 → 放行 → 扣库存 + 应收生成
- [ ] 来料登记生成应付；盘点校准库存；冲销流水完整
