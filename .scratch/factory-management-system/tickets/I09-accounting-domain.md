# I09 · 账目域（应收/应付/收付款/对账/利润/成本/导出）

Type: task
Status: open
Phase: ③ 仓储账目线
Blocked by: I08（应收来自出库、应付来自来料）
Spec: spec.md §7

## Objective

账目域全部实体：应收/应付/收款单/付款单/对账单/利润视图/月度成本/四表导出。

## Scope

- 应收：出库确认自动生成（客户/金额）；收款单核销
- 应付：来料登记自动生成；付款单核销
- 收款单：核销 + 预收双模式（一步生效 + 冲销纠错无草稿态）；营收=收款核销（现金收付制）
- 付款单：核销 + 预付双模式（与收款单同构）
- 对账单：按客户（出库明细+收款明细+期末余额）+ 账龄分桶（30/60/90+）逾期标红
- 利润视图：月度总览（营收-材料-人工-制费）+ 营收按客户下钻；成本不下钻
- 月度成本：固定六类手填（人工/电费/燃气/房租/折旧/其他）+ 材料自动汇总
- 四表导出：出库/收款/来料采购/付款明细（CSV/Excel，给外部做账）

## Acceptance

- [ ] 出库→应收→收款核销闭环；来料→应付→付款闭环
- [ ] 收款核销=营收（利润视图正确）
- [ ] 对账单/账龄标红正确；四表可导出
- [ ] **阶段③验收**：仓储账目业务闭环
