# I03 · 主数据界面（产品/客户/供应商/操作人）

Type: task
Status: open
Phase: ② 订单线（第一张业务票）
Blocked by: I01
Spec: spec.md §3

## Objective

主数据四实体可增删改——订单录入依赖客户档案和产品目录下拉，必须先有界面。

## Scope

- 产品目录：产品名 / 类型（英式乙炔/丙烷、美式乙炔/丙烷）/ 默认包装 / 默认工序路线（文本，可配置化后续票）/ 安全库存
- 客户档案：名称 / 联系人 / 结算方式 / 账期天数
- 供应商档案：与客户同构
- 操作人：姓名 / 绑定 PC / 备注（下拉可覆盖）
- 交互：列表 + 表单弹窗增删改，直接生效无草稿态（对齐票 09 原型）

## Acceptance

- [ ] 四个实体均能新增/编辑/删除，列表即时更新
- [ ] 表单校验：必填项、账期/安全库存为数字
- [ ] 术语对齐 CONTEXT.md（产品目录/客户档案/供应商档案/操作人）
