# 03 · 订单与计划单域模型

Type: grilling
Status: resolved
Blocked by: —

## Question

敲定「订单 → 计划单」的领域模型：

- 订单（Order）实体：客户、产品类型、数量、交期、备注等字段；状态机（草稿/确认/生产中/完成/取消？）
- 计划单（Plan Sheet）实体：从订单生成的生产计划单——产品类型、包装要求、备注字段的具体形态；一单一计划还是多单合并？
- 订单 → 计划单的生成规则与人工审核环节
- 敲定的术语同步写入根目录 CONTEXT.md（加载 grilling 与 domain-modeling 技能）

## Comments

### Round 1（2026-08-26）

- **产品主数据**：建产品目录——产品类型/默认包装/默认工序路线，订单从目录选；新 OEM 需求先入目录再下单 ✅
- **订单结构**：一单多产品——订单头（客户/单号/交期）+ 行项目（产品×数量×备注）✅
- **生成粒度**：**一单一计划单**（未采纳推荐的一行一计划单）——计划单内含订单全部产品行，计划单 = 该订单的整张生产任务单。设计含义：① 行级进度需在状态机/界面覆盖；② 排期按整张单作为一个任务单元的前提是各型号共享同一套工序路线（仅参数/耗时不同），该假设由票 05 结合票 04 工序数据验证 ✅
- **生成流程**：自动生成+审核——订单确认后系统按产品目录默认值自动生成计划单草稿，计划员审核确认后生效；目录默认值维护质量直接决定草稿可靠性 ✅

### Round 2（2026-08-26）

- **订单状态机**：最小五态——草稿/已确认/生产中/已完成/取消；生产中与已完成由计划单进度自动推导（无人工状态维护）；发货/收款不进订单状态，由仓储/账目域另行关联 ✅
- **计划单状态机**：生命周期五态——草稿（自动生成待审）/已确认（生效可排期）/生产中（任一行报工）/已完成（全部行达标）/已作废（未开工或订单取消联动）；行级完成数量聚合出整单状态；「是否已排期」由排期表关联反查，不进状态机 ✅
- **变更联动**：草稿重生成+确认后人工——计划单草稿态改订单自动重生成草稿；计划单已确认后订单变更系统标记差异并提醒，人工决定作废重开或编辑；生产进行中永不自动改单 ✅
- **包装要求**：行级结构化+备注——包装方式/单位数量（每盒只数/外箱规格）挂产品行，产品目录带默认值，计划单上可改（OEM 特殊要求覆盖）；文本备注兜底印字/标签/特殊说明 ✅

### Round 3（2026-08-26）

- **客户主数据**：建轻量客户档案（名称/联系人/结算方式），订单从档案选；应收账款与对账单（票 08）按客户归集 ✅
- **交期结构**：单头一个交期——一单一交期，符合 OEM 整单发货习惯；计划单排期时为唯一时间底线 ✅
- **订单金额**：订单行记单价 + 币种（USD/CNY 可选），订单金额自动汇总；票 08 营收/利润视图的数据源；生产侧不依赖 ✅
- **单号规则**：系统自动单号（SO-年-流水 / PS-年-流水）+「客户 PO 号」字段记录客户方订单号（OEM 对单必备）✅

## Answer

**订单 → 计划单域模型（2026-08-26，三轮 12 问敲定）**

### 主数据

- **产品目录（Product Catalog）**：产品类型 / 默认包装 / 默认工序路线；订单与计划单产品信息的唯一来源，新 OEM 需求先入目录再下单
- **客户档案（Customer）**：轻量——名称 / 联系人 / 结算方式；订单与应收账款的归集主体

### 订单（Order）

- 结构：单头（客户档案引用、单头交期、客户 PO 号、备注）+ 多订单行（产品目录引用 × 数量 × 单价+币种 × 行级包装要求 + 行备注）
- 状态机（最小五态）：草稿 →(人工确认)→ 已确认 →(自动：计划单开工)→ 生产中 →(自动：计划单完成)→ 已完成；任意未完成状态可(人工)取消；生产中/已完成为派生状态，无人工维护
- 单号：系统自动 SO-年-流水；另记客户 PO 号

### 计划单（Plan Sheet）

- 生成：订单确认时系统自动生成 **1 张**计划单草稿（一单一计划单，含全部订单行，预填目录默认值），计划员审核通过后生效
- 行结构：产品 / 计划数量 / 包装要求（结构化：包装方式+单位数量，目录默认可覆盖）+ 文本备注（印字/标签/特殊说明）；行完成数量实时记录
- 状态机（生命周期五态）：草稿 →(人工审核)→ 已确认 →(自动：任一行报工)→ 生产中 →(自动：全部行达标)→ 已完成；草稿/已确认 →(人工)→ 已作废；「是否已排期」由排期表关联反查，不进状态机
- 交期：继承订单单头交期作为排期时间底线（具体排期归票 05）

### 变更联动

- 计划单草稿态：订单变更 → 自动重生成草稿
- 计划单已确认：订单变更 → 系统标记差异并提醒，人工决定作废重开或编辑
- 生产进行中：永不自动改单；已开工计划单不可作废，订单生产中取消属例外场景，人工处置

### 默认实现约定（未单独提问，落地按此）

- 行完成数量 ≥ 计划数量即行完成，允许记录超出（返工/余量）
- 币种枚举 USD/CNY 起步
- 订单生产中/已完成为计算属性（派生），非人工可写字段

### 挂起假设（由票 05 验证）

- 排期按整张计划单作为一个任务单元，前提 = 各型号共享同一套工序路线、仅参数/耗时不同
