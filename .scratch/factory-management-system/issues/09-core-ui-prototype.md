Type: prototype

## Question

用一次性可点原型回答「核心界面长什么样、交互顺不顺」：

- 三个关键界面：订单录入 → 计划单生成 → 排程看板
- 加载 prototype 技能；原型代码放独立目录/分支，票据里留链接
- 用户过目反馈后，结论折进规格（原型本身是一次性资产，不留进主干）

## Answer

### 形态决策（2026-08-27，用户确认）

- **原型范围**：三界面串流程——订单录入 → 计划单生成 → 排程看板，数据真实流动 ✅
- **原型形态**：单文件可点 HTML——模拟数据、可点击交互、不接后端、双击即开 ✅
- **流程可点性**：全流程可点——录单→确认→看草稿→审核→拖排期→看报工状态变化 ✅
- **反馈机制**：内嵌反馈点——每界面底部「像不像/哪里不对」按钮，反馈折进规格 ✅

### 演示的核心链路（串联前 11 张票决策）

1. **订单录入**：选客户档案 → 加产品行（目录选择 × 数量 × 单价币种 × 包装要求）→ 填交期/客户PO号 → 确认
2. **计划单生成**：确认后自动出现草稿（预填目录默认值）→ 计划员审核
3. **排程看板**：审核后的计划单进待排区 → 甘特图拖到时间槽 → 报工后任务块变色

### 原型位置

- 原型文件：`.scratch/factory-management-system/prototypes/09-core-ui/index.html`（一次性资产，独立于主干）
- 使用：浏览器直接打开，按顶部 ①订单录入 → ②计划单生成 → ③排程看板 走完整流程
- 演示路径：选客户 → 加产品行（目录自动带出包装）→ 确认 → 看计划单草稿 → 审核 → 看板拖排（或双击快速排期）→ 报工看任务块变色
- 反馈：每屏底部「像想要的/缺字段/交互别扭/其他问题」按钮，反馈记录在浏览器内存与页面底部汇总
- 状态：✅ 原型已建待用户过目（2026-08-27）
