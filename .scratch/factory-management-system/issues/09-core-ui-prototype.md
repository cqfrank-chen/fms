# 09 · 核心界面原型

Type: prototype
Status: claimed
Claimed: 2026-08-27
Blocked by: 03, 05

## Question

用一次性可点原型回答「核心界面长什么样、交互顺不顺」：

- 三个关键界面：订单录入 → 计划单生成 → 排程看板
- 加载 prototype 技能；原型代码放独立目录/分支，票据里留链接
- 用户过目反馈后，结论折进规格（原型本身是一次性资产，不留进主干）

## Answer

### 形态决策（2026-08-27，用户确认）

- **原型范围**：三界面串流程——订单录入 → 计划单生成 → 排程看板，数据真实流动 ✅
- **原型形态**：单文件可点 HTML——模拟数据、可点击交互、不接后端、双击即开 ✅
- **流程可点性**：全流程可点——录单→确认→看草稿→审核→拖排期→看报工状态变化 ✅
- **反馈机制**：内嵌反馈点——每界面底部「像不像/哪里不对」按钮，反馈折进规格 ✅

### 演示的核心链路（串联前 11 张票决策）

1. **订单录入**：选客户档案 → 加产品行（目录选择 × 数量 × 单价币种 × 包装要求）→ 填交期/客户PO号 → 确认
2. **计划单生成**：确认后自动出现草稿（预填目录默认值）→ 计划员审核
3. **排程看板**：审核后的计划单进待排区 → 甘特图拖到时间槽 → 报工后任务块变色

### 原型位置

- 原型文件：`.scratch/factory-management-system/prototypes/09-core-ui/index.html`（一次性资产，独立于主干）
- 使用：浏览器直接打开，按顶部 ①订单录入 → ②计划单生成 → ③排程看板 走完整流程
- 演示路径：选客户 → 加产品行（目录自动带出包装）→ 确认 → 看计划单草稿 → 审核 → 看板拖排（或双击快速排期）→ 报工看任务块变色
- 反馈：每屏底部「像想要的/缺字段/交互别扭/其他问题」按钮，反馈记录在浏览器内存与页面底部汇总
- 状态：✅ 原型已建待用户过目（2026-08-27）

### 用户反馈 v1（2026-08-28）→ 已确认修订

1. **包装要求结构化**：订单行包装从文本框升级为多选项（包装盒/不干胶/纸箱…）+ 可上传样式图保存为模板 + 自定义 + 模板复用 ✅
2. **计划单列表增强**：加「反查来源订单详情」入口 + 按客户/状态/交期筛选 ✅
3. **排程看板核验**：拖完弹核验面板——占用哪些工序产能/预计完工日/是否超交期（红），计划员确认或调时间 ✅
4. **订单查询/归档界面**：订单列表按状态筛选（草稿/已确认/生产中/已完成/已取消），已完成折叠进归档区可按客户/日期反查 ✅
5. **排程单元修订（票05决策修订）**：从「计划单级」改为「计划单行级」——每个产品行一个可拖拽任务块，分别拖排/分别报工；计划单状态仍由行进度聚合（票03状态机不变）✅
   - 影响：票 05 第一轮 Q1「排期单元=计划单级」修订为「计划单行级」；甘特图按行显示任务块

### 原型 v2 状态

- 状态：✅ 原型 v2 已构建待用户过目（2026-08-28）——实现 5 条修订：包装模板库（4 个种子+上传保存+复用）、订单列表筛选+归档区反查、计划单列表筛选+来源订单反查、拖排核验面板（工序/工期/交期判断）、排程单元行级化（每产品行一任务块分别拖排报工，计划单状态由行聚合）

### 用户反馈 v2（2026-08-28，对话口述）

1. **包装要求是复合选项**：同一订单行可能同时需要 包装盒+是否套袋+纸箱+不干胶 多项——v2.2 改为四类勾选（box/bag/carton/label）+ 每项填规格 ✅
2. **上传新样式形式疑问**：解释为「保存包装模板」弹窗——名称/类型/规格说明/样式图上传（正式系统接文件上传），保存后可复用 ✅
3. **订单详情/反查无法点击**：根因是 alert() 被预览沙箱拦截——v2.2 全部改为自绘 modal 弹窗 ✅
4. **订单不走冲销**：澄清——冲销只用于单据纠错（票06/08：出入库单/收付款单）；订单改单走票03「变更联动」（草稿重生成/确认后人工处置）✅
5. **双击/拖排失效**：根因是 HTML5 原生拖放在 iframe 沙箱受限——v2.2 改为「点击待排任务 → 排期面板（选工序+开始日+核验）」不依赖拖放 ✅
- 状态：🔄 原型 v2.2 已构建（修复弹窗/拖排/复合包装），待用户过目（2026-08-28）

### 用户反馈 v3（2026-08-28，对话口述）

1. **图片识别自动导入**：新建订单加「📷 图片识别导入」入口——模拟票10 AI 订单解析（上传图片→自动填客户/PO/交期/产品行/刻字/包装，低置信度标红待人工确认）✅
2. **详情/反查还是点不开**：根因定位升级——不是 alert()，是**内联 onclick 属性被预览环境 CSP 拦截**。v2.3 全部改事件委托（document 级 addEventListener + data-* 属性），内联事件清零 ✅
3. **订单行加刻字需求**：每行加「刻字需求」字段（LOGO/型号/批次等 OEM 常见），贯穿订单→计划单→排期任务展示 ✅
4. **排程还是不能点击排期**：同上根因（内联 onclick 被拦）——v2.3 改为事件委托后点击任务弹排期面板 ✅
- 状态：🔄 原型 v2.3 已构建（事件委托修复 + AI 导入 + 刻字字段），待用户过目（2026-08-28）
