# 08 · 账目口径建模

Type: grilling
Status: resolved
Claimed: 2026-08-27
Resolved: 2026-08-27
Blocked by: 03✅, 06✅

## Question

敲定账目统计域模型（口径已定：经营统计 + 往来账款）：

- 经营统计：订单营收、物料成本、生产成本（人工/制费的分摊口径？）、利润视图的计算口径
- 往来账款：应收（挂订单）、应付（挂采购/领料）、对账单、账期与提醒
- 与外部做账系统的边界：只导出、不重复记账

## Answer

四轮 16 个决策点，全部按推荐或用户选择落定。

### 第一轮（2026-08-27）：营收口径 + 成本口径 + 应收结构 + 应付结构

- **营收确认时点**：收款即营收（现金收付制）——出库只生成应收记录，营收在收款核销时才确认。利润=实际回款-采购-人工-制费，最保守最真实。接受「应收在途期间利润表看不到这单贡献」的代价 ✅
  - 用户初选「收款即营收」，经确认保留此选择（非随手选）
- **成本口径**：期间成本汇总——材料采购按月从来料登记单金额合计（买了就算花了，不按消耗算）；人工/制费月度手填。利润视图=月营收-月采购-月人工-月制费。给的是宏观利润，不追订单级实际成本 ✅
  - 约束来源：票06定了原料纯登记不联动生产、无领料扣减、无MRP；人工/制费无报工耗时数据可分摊
  - 用户初选「期间成本汇总」，经确认材料按采购算不按消耗算能接受
- **应收账款**：出库确认时自动生成应收记录（客户/金额=出库数量×单价），收款单核销（部分核销=部分回款）✅
- **应付账款**：来料登记单加「金额」字段后自动生成应付记录（供应商维度），付款单核销；其他采购开独立采购付款单 ✅

### 第二轮（2026-08-27）：多币种 + 收款单结构 + 对账单 + 导出边界

- **多币种处理**：一期单币种 RMB——用户确认目前只有 RMB 收支。订单行币种字段保留（票03已定），出海落地后再升级多币种折算 ✅
- **收款单结构**：核销+预收双模式——核销式指定冲抵哪张出库的应收（部分核销=部分回款）；预收式先挂客户预收余额不指定订单，出库后用预收余额核销。覆盖 OEM 常见 30%定金+70%尾款场景 ✅
- **对账单与账期**：按客户生成对账单（期间出库明细+收款明细+期末余额）；账龄分桶标红（30/60/90+天），无推送，与票06安全库存标红同风格 ✅
- **导出边界**：四表导出——出库明细/收款明细/来料采购明细/付款明细+汇率表，CSV/Excel格式给外部做账系统导入；不做凭证、不做科目映射 ✅

### 第三轮（2026-08-27）：利润视图 + 成本手填结构 + 付款单结构 + 账期规则

- **利润视图**：两层——月度利润总览（营收-材料-人工-制费-利润一张表）+ 营收按客户/产品下钻。成本不下钻（期间制无分摊基础，硬分摊是假数据）✅
- **成本手填结构**：固定六类枚举——人工（工资+社保）/电费/燃气/房租/折旧/其他，每月每类填一笔。类目固定不可自定义，趋势统计才不会乱 ✅
- **付款单结构**：核销+预付双模式——与收款单同构，核销式指定冲抵来料登记单/采购付款单的应付，预付式先挂供应商预付余额到货后核销。覆盖铜棒供应商先打款后发货场景 ✅
- **账期规则**：客户档案加「账期天数」字段，应收到期日=出库日+账期天数，账龄从到期日起算（未到期不分桶，逾期才标红）。定金已收部分不进账龄，只有尾款部分算逾期 ✅

### 第四轮（2026-08-27）：供应商主数据 + 收付款单状态机 + 预收退款

- **供应商主数据**：轻量供应商档案（名称/联系人/结算方式），与客户档案同构。来料登记单和付款单从档案选 ✅
- **收付款单状态机**：一步生效+冲销纠错——录入即生效无草稿态（收付款是银行事实不是计划）；错单冲销，与票06出入库单纠错同构 ✅
- **预收退款**：负向登记——记一笔负向预收（金额/日期/备注），余额减少；银行转账线下处理，系统只登记留痕。供应商预付退款同理 ✅

### 挂起假设（记入票据，非隐患）

1. **预收→应收核销**：核销操作时可选来源（新收款或预收余额），不单独建操作
2. **冲销联动**：出库单冲销→应收记录同步冲销；来料登记单冲销→应付记录同步冲销
3. **非来料零星挂账采购**：由来料登记单兼容（物料名填服务名、批次号留空、检验状态设免检）

### 已知代价（选择而非隐患）

1. 应收在途期间利润表看不到这单贡献（现金收付制固有特征）
2. 屯料月利润偏低（材料按采购算不按消耗算的简化）
3. 退货补发损耗票08看不见（票06定了一期不做退货补发）
