  工厂管理系统 FMS · 一键安装说明
════════════════════════════════════════
  版本：72a33c1（2026-09-26）— 详见同目录 REVISION.txt｜AI 已预置可用 Key｜支持本地域名

【怎么装】只做一件事：
   双击  setup.bat
   弹出「用户账户控制」窗口时点【是】。
   然后全程自动，无需任何操作。

   脚本自动完成（约 10-30 分钟，视网络）：
   ① 安装 Docker Desktop（本机没装时自动下载安装，约 500MB）
   ② 启动 Docker 引擎（首次 1-3 分钟）
   ③ 生成配置 → 构建系统 → 启动服务（首次 5-15 分钟）

   中途如果提示「需要重启一次」：
     重启电脑后，再双击 setup.bat 即可自动续装，不会重复下载。

【怎么用】
   安装完成后浏览器打开：
     本机：    http://localhost      或  http://fms.local（绑定本地域名后）
     厂内其它电脑： http://fms.local   或  http://本机IP（IP 在安装完成窗口里有提示）

【本地域名（推荐，免记 IP）】
   进入 system\ 目录，双击  set-domain.bat（弹窗点【是】提权），之后即可用：
       本机          http://fms.local
       其他电脑      在该电脑运行  set-domain.bat -Ip 服务器IP
       全厂免逐台    在路由器 / 内网 DNS 加一条 A 记录：fms.local -> 服务器IP
   它只修改本机 hosts（Windows 标准做法），不影响系统其它设置；
   解除绑定：set-domain.bat /remove    仅预览：set-domain.bat 加 -PrintOnly

   登录后点左侧菜单即可使用：订单 / 计划单 / 排程 / 仓储 / 账目 / AI 助手。
   初始管理员：admin / Fms@2026（首次登录后请点右上角「修改密码」；菜单按角色显示，
   账号与角色在「设置 · 主数据 → 用户账号与角色权限」里维护）

【自动更新（可选，推荐）】
   1) 服务器上双击运行  system\auto-update.bat  →  选「安装为计划任务」
      （每 5 分钟检查一次更新请求；安装后设置页会显示「宿主更新代理：在线」）
   2) 之后在系统内「设置 · 系统更新」卡片点【一键更新】即可：
        比对 GitHub 最新版本 → 下载更新包 → 宿主代理自动执行
        「备份数据库 → 更新代码 → 重建镜像并重启 → 健康校验」，约 1-3 分钟
   3) 未安装代理时：点【一键更新】只会下载更新包，需在服务器上运行 system\upgrade.bat
   其它命令：auto-update.bat run（立即检查）/ status（查看状态）/ uninstall（移除任务）

【日常维护】
   · 升级系统：拿到新版后，把 system 文件夹整体覆盖到本目录，
     再双击 system\upgrade.bat（数据不会丢）
   · 数据备份：双击 system\backup.bat
     （重要：建议加入 Windows 计划任务，每日自动执行）
   · 改端口 / 填 AI key：编辑 system\.env（首次运行后自动生成）
     - 端口：HTTP_PORT=80  ← 改成 8080 等
     - AI：AI_API_KEY=sk-xxx（DeepSeek）填好后重跑 setup.bat 生效

【离线安装（没网或网慢）】
   先去 https://www.docker.com/products/docker-desktop/ 下载
   "Docker Desktop Installer.exe"（约 500MB），放进本目录的
   docker\ 文件夹，再双击 setup.bat —— 将直接本地安装、不联网下载。

【开发者：打包发布（本地与 CI 现状）】
  一条命令产出两个包（本地已验证）：
    powershell -File packaging\build-package.ps1                # 瘦包（不含 Docker 安装器）
    powershell -File packaging\build-package.ps1 -Fat           # 胖包（自动放入 Docker Desktop 安装器）
    powershell -File packaging\build-package.ps1 -Version v1.0.7 -OutDir D:\futures
  产物：
    fms-system-<ver>.zip   仅 system/（自动更新用，约 350KB）
    fms-setup-<ver>.zip    完整安装包（system/ + setup.bat + 安装说明.txt + docker/）
    fms-发布包\            解压后的目录，可直接使用（会保留已有 system\.env，不丢 AI Key）
  说明：
    · 包装文件（setup.bat / 本说明 / docker-README.txt）的版本管理来源是 packaging\；
    · CI（GitHub Actions，推送 v* tag 触发）目前使用内联组装流程出包，尚未调用该脚本；
      两者产物结构一致，仅"由谁组装"不同（已知小债，见 Review 报告）；
    · Linux 云服务器（Ubuntu/Debian）部署见 deploy/deploy-linux.sh：
      sudo bash system/deploy/deploy-linux.sh —— 自动建 swap、装 Docker、配国内镜像源、
      随机化数据库口令与 JWT_SECRET、docker load 离线镜像后 --no-build 启动并做健康检查。

【WSL2 内核兼容性（Win10 新机必读）】
  · Windows 10（1903–21H2）：需要 docker\wsl_update_x64.msi，setup.bat 会自动静默安装
  · Windows 11 / 较新 Win10：内核已内置（或为 Store 版 WSL），setup.bat 检测 WSL 可用即跳过
  · 包内该文件 SHA256：4D09C776C8D45F70A202281D18E19BE1118F5315…（16.3MB）
  · 若目标机缺该文件：从已装好的机器 C:\Users\<用户>\Downloads 拷入 docker\ 即可
  · 说明：Docker Desktop 自带 docker-desktop 发行版，无需从 Microsoft Store 下载 Ubuntu
